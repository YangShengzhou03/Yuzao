# ADR-011 — USD 仅作视图/拾取层

- 状态：已采纳
- 日期：2026-11-01

## 背景
需要在 3D 画布渲染模型并支持点选特征做自然语言微调（G2）。

## 决策
USD（`.usda` + 特征 ID 元数据）**只承载视图与拾取**，不承载参数化真值；任何编辑都回到 Creo 执行。

## 理由
Creo 无 USD 导出组件，必须自建 `Creo → STEP/VRML/STL → .usda(+customData.featureId)` 视图桥；让 USD 参与建模会破坏特征树真值。

## 影响
视图层与真值层解耦；前端渲染/拾取读 USD，编辑指令经 Rust 调度层回传 Creo。
