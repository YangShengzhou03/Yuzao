# ADR-012 — LLM 只输出 FeatureSpec JSON

- 状态：已采纳
- 日期：2026-11-01

## 背景
让 LLM 直接写 Toolkit API 调用/脚本/trail 易产生幻觉与不可控输出。

## 决策
LLM 只输出受控 JSON（FeatureSpec IR）：`features` 建、`edits` 改，结构相同；拓扑引用 `F002.face[top]` 由 Rust 特征 ID 映射表解析，LLM 永不猜 face index。

## 理由
约束输出空间，杜绝"AI 零幻觉"；后端按 id 定位特征 → 改参 → `Regenerate`，天然满足 G3。

## 影响
新增 `spec/` 目录定义 FeatureSpec（见 `spec/featurespec.example.json`）；Rust 调度层负责 JSON 校验与 Creo 调用翻译。
