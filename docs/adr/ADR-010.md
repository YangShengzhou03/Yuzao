# ADR-010 — 内核接入优先 R2，R1 作为先导

- 状态：已采纳
- 日期：2026-11-01

## 背景
驱动本机 Creo 有 R1（OTK 异步 exe）、R2（Toolkit DLL 内嵌）、R3（J-Link）、R4（Trail）、R5（Pro/PROGRAM）、R6（FreeCAD）等路线。

## 决策
- **主线 R2**（Toolkit DLL / C API）：能力最全，唯一能完整满足 G1–G4，作为生产级目标。
- **先导 R1**（OTK 异步 exe）：用最快时间验证闭环，代码与 R2 共用 pfc 语义、可迁移。
- R5 作参数微调补充；R6 仅作无 Creo 客户的降级备胎；R4 禁做产品线。

## 理由
R2 的 C API 暴露完整参数化能力；R1 分层最干净、调试最友好，可先跑通商业闭环。

## 影响
`native/` 按路线分目录：`r1_otk/`（先导）、`r2_toolkit/`（主线）、`r5_program/`（补充）、`creo_bridge/`（正式内核落点）。
