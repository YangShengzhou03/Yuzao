# ADR-009 — 真值内核切换到客户本机 Creo

- 状态：已采纳
- 日期：2026-11-01

## 背景
原方案以 FreeCAD 为内核，但其产出的 FCStd/STEP 不是原生 Creo `.prt`，工程师在 Creo 中拿到的是导入实体（无特征树），不满足目标 G4（原生可编辑）。

## 决策
放弃 FreeCAD 作为主路线，真值内核切换到**用户本机已授权的 Creo Parametric**；本产品定位为运行在客户已授权 Creo 之上的伴侣程序，不分发 Creo 本体。

## 理由
只有 Creo 能生成 Creo 原生特征树 `.prt/.asm`，使 G1–G4 全满足。

## 影响
所有几何真值由 Creo 承载；USD 仅作视图/拾取层；需客户侧合法持有 Creo + Toolkit 授权。
