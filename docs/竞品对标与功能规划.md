# 竞品对标与功能规划：如何与 AutoCAD / 浩辰CAD / 中望CAD 抗衡

> 本文回答一个战略问题：要具备哪些功能点，语造才能在市场中与三大竞品正面竞争。
> 结论先行：**不能正面硬刚 2D 制图（那是 40 年护城河 + DWG 锁定 + 庞大二次开发生态），
> 而应以「AI 原生参数化建模 + USD 协作数据模型 + 信创国产化」为楔子，
> 把 DWG 兼容做成"迁移跳板"而非主战场。**
>
> **生效说明（2026-11-01）**：本文是**市场与功能视角的战略输入**，不定义执行排期。
> 执行排期与阶段定义以 [`ROADMAP.md`](../ROADMAP.md) 为唯一权威（P0–P6，执行任务编号 `P{n}.{k}`）。
> 文中遗留的 `Phase 1 / Phase 1.5 / Phase 2 / Phase 4` 等旧编号**已废止**，§5 给出旧→新映射；
> 功能优先级与路线图排期冲突时，以路线图为准，调整排期须走变更评审（见 ROADMAP §9）。
> **编号约定**：本文 `T0–T4` 为**市场优先级层级**；`ROADMAP.md` 的 `P{n}.{k}` 为**执行任务编号**，二者是不同命名空间，禁止混用。

## 1. 竞品定位速写（基于公开信息，2025–2026）

| 竞品 | 真实定位 | 关键能力 | 对我们的含义 |
|---|---|---|---|
| **AutoCAD** | 2D 制图事实标准 + 轻量 3D | DWG 原生、AutoLISP/.NET/ObjectARX、动态块、参数化约束、图纸集、行业工具集 | 生态锁定极强；DWG 是入场券 |
| **浩辰CAD** | 国产 AutoCAD 替代（2D 强） | DWG 全兼容、GRX/.NET/LISP、2D+3D、协同/云、性价比 | 价格与本地化是其主要武器 |
| **中望CAD / 中望3D** | 国产全栈（2D+3D+AI+信创） | 自主内核、参数化、**已发布 AI（AI-structure Copilot，与清华合作）**、**信创（麒麟/鸿蒙/统信）**、光栅矢量化、点云、多端协同 | **最强对手**：AI 与信创已是既成事实，我们必须在"AI 深度"和"协作模型"上更狠 |

**关键认知**：中望已把 AI、自主内核、信创做成产品级能力。因此"我们靠 AI 就能赢"**不成立**——
我们的 AI 必须是**原生建模闭环**（自然语言→参数化特征树→可回溯编辑），而非"AI 帮点按钮"的助手型。

## 2. 战略前提：不正面硬刚，做差异化楔子

1. **DWG 是入场券，不是胜负手**：用 ODA Drawings SDK（排期见 ROADMAP P4.4，授权门禁）做到"能读、能改、能写"，
   让用户敢把历史图纸迁进来；但不与 AutoCAD 比 2D 绘图细节的完备度。
2. **2D 制图是底线，3D 参数化是主战场**：AutoCAD/浩辰/中望的 2D 是存量护城河；
   而**真·参数化特征建模**（特征树 + 稳定拓扑命名 + 可编辑历史）恰恰是它们的相对薄弱处（中望3D 有，但非 AI 原生）。
3. **AI 要"生成+可编辑"，不是"助手"**：竞品的 AI 多为命令助手/专项生成（如结构生成）；
   我们的差异是 **自然语言端到端建模 + 在已有模型上增量改参 + 撤销重做**（P1 进行中，真实 LLM 接入在 P5）。
4. **USD 协作数据模型是它们没有的**：图层式版本、git 式差异合并、多人并发——这是 OpenUSD 的天然优势。
5. **信创/国产化是入场门槛（中国市场）**：必须支持 Linux（麒麟/统信）、鸿蒙/移动端、国产 CPU 适配。

## 3. 功能点分层清单（T0=生死线 → T4=差异化；市场优先级层级）

> `T0–T4` 仅表达市场优先级，不等于执行阶段；执行落点一律引用 `ROADMAP.md` 的 `P{n}.{k}`。

### T0 — 入场生死线（不做就无法进入市场）
- **DWG/DXF 双向兼容**：读取、编辑、写回（含图层/块/标注/文字），ODA 兜底（排期见 ROADMAP P4.4，授权门禁）
- **2D 绘图核心**：直线/多段线/圆/弧/椭圆/样条、夹点编辑、对象捕捉/追踪、坐标输入
- **图层 / 线型 / 线宽 / 颜色**：图层管理器、打印样式
- **块(Block) 与属性**：普通块、属性块、**动态块**（竞品强项，需对标）
- **尺寸标注与公差**：线性/对齐/半径/直径/角度、形位公差、标注样式
- **文字 / 表格 / 引线 / 注释**
- **打印出图**：布局/视口/比例/打印样式表(CTB/STB)、批量打印
- **精确绘图基础设施**：正交/极轴/对象约束（几何+尺寸约束的 2D 部分）

### T1 — 工程提效（与竞品正面对标）
- **2D 参数化约束**：几何约束 + 尺寸驱动（改尺寸→图形联动）
- **字段 / 属性提取 / 数据链接**：BOM 表、明细表自动生成
- **外部参照 Xref**、**图纸集(Sheet Set)**、电子传递
- **批量处理**：文件比较、批处理脚本、PDF/DWG 互导
- **二次开发生态**：LISP 兼容 + .NET/Python SDK + 自建 AI 工具面（迁移存量插件用户）
- **光栅图像矢量化**：手绘/扫描图→CAD（中望已有，属加分项）
- **点云附着与拟合**（测绘/逆向场景）

### T2 — 3D 与参数化（我们的主战场，竞品相对薄弱）
- **参数化特征树 + 稳定拓扑命名**（见 `docs/ARCHITECTURE.md` §3–§4；P1 探针进行中，见 `native/r2_toolkit`；P3 补复杂特征传播）：草图→拉伸→孔→倒角可编辑
- **直接建模**（无历史修改，作为补充）
- **装配 / 配合约束 / BOM 导出**
- **工程图自动投影**：3D→2D 三视图、剖视、局部放大、自动标注、标题栏/明细表联动
- **钣金 / 曲面 / 实体**（按行业定位取舍）
- **设计变量 / 方程式 / 配置(Configuration)**

### T3 — AI 差异化（我们独有，竞品未做深）
- **自然语言生成模型**：一句话出参数化模型（P1 进行中（FeatureSpec / 特征探针验证）；P5 接入真实 LLM）
- **对话式增量改参**：选中特征/面→自然语言改参→重算（拓扑命名保证不崩）
- **生成式设计 / 方案推荐**：给定约束自动生成多方案
- **图纸智能识别与转换**：旧图/PDF→参数化特征（而非哑实体）
- **自动标注 / 智能检查**：规范校验、干涉检查
- **多 Agent 协同**：草图/特征/校验/出图各司其职（ROADMAP P5.2）

### T4 — 国产替代与生态（决定中国市场成败）
- **信创适配**：麒麟/统信/UOS、鸿蒙、国产 CPU（鲲鹏/飞腾/龙芯）（排期见 ROADMAP P6.4）
- **多端协同**：桌面/网页/移动端一致体验（中望已做，需对标）（排期见 ROADMAP P6.1）
- **云原生协作**：多人实时编辑、版本树（USD Layering 天然支持）（排期见 ROADMAP P6.2/P6.3）
- **授权与性价比**：永久/订阅/按量；对标浩辰/中望的低价策略
- **行业解决方案与零件库**：标准件库（中望内置 40 万零件）、机械/建筑/电气模板
- **本地化服务与培训**：中文生态、认证体系

## 5. 与权威路线图的衔接（旧编号映射与补强建议）

> 本节旧编号（`Phase 1.5`、`Phase 2–3`、`Phase 3/5` 等）仅为历史表述，**不得用于排期或验收**；

| 旧表述 | 现行阶段 / 任务 | 说明 |
|---|---|---|
| `Phase 1`（自然语言画布，FreeCAD 时代） | **P1**（进行中） | 当前为 Creo 特征探针（`native/r2_toolkit`），见 ROADMAP P1.1–P1.4 |
| `Phase 1.5`（建议新增 2D） | **P4** P4.2/P4.3 | 2D 绘图/标注已纳入 P4（ROADMAP P4.2/P4.3），不再单列 1.5 |
| `Phase 2`（接 OCCT/C++，FreeCAD 时代） | **无现行对应**（内核能力由 P1–P3 承担） | 内核已切换为 Creo（ADR-009）；FreeCAD 仅作 R6 降级（见路线对比）。旧 OCCT/C++ 描述废止 |
| `Phase 2–3`（工程图/BOM） | **P4** P4.5/P4.6 | 工程图投影 / BOM 在 P4 落地（ROADMAP P4.5/P4.6）；`TechDraw` 为 FreeCAD 时代术语，废止 |

| `Phase 4`（DWG/PRT） | **P4** P4.4（DWG） | DWG 受 ODA 授权门禁；原生 `.prt` 由 R1/R2 始终产出（G4），不属 P6、不作独立任务 |
| `Phase 5`（AI/云化） | **P5**（AI 闭环）/ **P6**（云化协同） | 拆分为"AI 先行（P5）、协同后置（P6）" |

**对路线的三条补强建议（需提交变更评审，不自动生效）**：

1. **2D/DWG 的优先级**：路线图已把 DXF/2D/标注放在 P4（ROADMAP P4.1–P4.3）、DWG 放 P4.4；
   若市场窗口要求提前，需在 P3 验收评审处提出"提前 DWG 读取（只读）"，并确认 ODA 授权；
   未获授权时一律按 DXF 降级路径执行，不阻塞 3D 主线。
2. **信创适配**：路线图排在 P6（ROADMAP P6.4，Linux/麒麟/统信/国产 CPU）。若政企项目强约束，
   可提前到 P4 末做"Linux 构建可行性 PoC"，但不改变 P6 的正式交付门禁。
3. **AI 定位**：从"命令助手"升级为"建模闭环 + 可编辑历史"——已写入 ROADMAP P5（AI 建模闭环目标），无需改路线。

## 7. 一句话总结

> **用 DWG 兼容把用户"接进来"，用 AI 原生参数化建模 + 稳定拓扑命名把效率"提上去"，
> 用 USD 协作与信创国产化把壁垒"筑起来"——不与 AutoCAD 比 2D 功能数量，
> 而在"建模方式"和"协作数据模型"上换赛道竞争。**
